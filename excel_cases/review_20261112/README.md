# Независимые учебные Excel — 12.11.2026

Десять карточек созданы для проверки разных исходов обработки. `manifest.json`
содержит цели и ожидаемые свойства, заданные до первого запуска; `SHA256.json`
фиксирует исходные файлы. После получения ответов модели карточки не менялись.
Возраст и суммы вымышлены, персональных данных нет. Названия препаратов реальные,
кроме явно вымышленного средства в сценарии 03. Это не назначение лечения.

Сценарии: 01 обычный; 02 препарат другого назначения; 03 неизвестное средство;
04 без возраста; 05 комбинация МНН; 06 повторные покупки и разные валюты;
07 отрицательная сумма; 08 повторный ID; 09 формула вместо суммы;
10 устаревший XML-диапазон при фактически существующих двух покупках.

Офлайн-проверка всех карточек входит в `tests/test_independent_excel_cases.py`.
Реальный полный сценарий из корня проекта:

```powershell
.\.venv\Scripts\python.exe run_excel_scenario.py --input-dir excel_cases/review_20261112/input
```

Команда расходует токены GigaChat на семи допустимых карточках. Три намеренно
ошибочные карточки отклоняются до API; поэтому общий код Python ожидается 2.
Отсутствие категории и необходимость клинической сверки допустимы по манифесту;
нельзя подменять их выдуманной категорией ради успешного результата.

Историческая проверка после исправлений 12.11: семь отчётов без API-ошибок и
fallback, три ожидаемых отказа входа; 27 запросов / 27 ответов, 92 446 токенов.
Сверены 41 цитата со снимками и HTML, суммы, валюты, строки и SHA. Это проверка
перечисленных свойств, а не медицинская приёмка и не измерение точности 95%.
Сгенерированные отчёты, кэши и настройки окружения в репозиторий не включаются.
