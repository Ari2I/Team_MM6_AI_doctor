# Сопоставление препаратов и классификация ML-2

Пакет `llm_rag.ml2` — часть этой библиотеки. Он определяет МНН по переданному
снимку реестра, выбирает клинические источники при явно разрешённой загрузке,
проверяет структурированный ответ классификатора и дословность цитат.
Рабочая политика `ml2-policy.4` не объявляется утверждённой политикой комиссии.
NOT_FOUND/NO_EVIDENCE и противопоказание не превращаются автоматически в В.

## Интерфейсы

- `RegistryIndex.resolve` — локальное сопоставление названия и доступных форм.
- `ML2Pipeline.evaluate_pair` — узкая пара без обязательных денег/количества;
  используется новым [фасадом](../../../docs/integration-result.md).
- `ML2Pipeline.run` — прежний однодиагнозный AnalysisRequest, с обязательными
  полями Original; его контракт без учебного флага. Новый фасад принимает null.
- `classify_pair` — роль/условия/цитаты по уже предоставленным фрагментам.
- `form_matching.match_form` — MATCH/MISMATCH/UNKNOWN концентрации отдельно от
  МНН и схемы приёма. Неизвестные преобразования не угадываются.

Полные источники/статусы хранятся в ML2Batch.details, не в строке комментария.
Разные редакции одного фрагмента сохраняются с составной идентичностью;
для модели используются временные ключи с обратным восстановлением.

## Источники

Рабочий фасад использует официальный каталог и тексты Минздрава через
`ml2.official.ClinicalSources` и выгрузку ГРЛС через `ml2.grls`.
Команда локальной проверки и настройки описаны в [README](../../../README.md).
