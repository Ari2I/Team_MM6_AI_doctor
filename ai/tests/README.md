# Проверки библиотеки

Запуск из корня: `python -m pytest -q`. Набор бесплатный, не использует ключи,
сеть и локальные веса. Временные файлы размещаются в .local/tmp/pytest.

| Группа | Что проверяет |
| --- | --- |
| test_integration* | ID и ссылки, nullable/Decimal, категории/валюты, result round-trip, provenance, human_report, бюджеты, lifecycle, ошибки пар и модельный адаптер на локальном клиенте |
| test_network_payload_policy / test_gigachat / test_generation | Сетевой allowlist, временные ключи, минимизация полей, настоящий SDK с подменённым HTTP, TLS/ошибки/схемы |
| test_gigachat_embeddings / test_embedding_runtime / test_vectors | Порядок/размерность/числа векторов, запрет непубличных текстов, атомарный общий кэш, отсутствие локальных моделей, независимые тестовые векторы |
| test_rag_data | Права/путь/SHA, неизменность активного набора при сбое, повторная подготовка и RAG_DATA_DIR |
| test_multidiagnosis_fixtures / test_independent_excel_cases | Независимые XLSX и их предварительные manifest/SHA; старые файлы не подгоняются под результат |
| ml2/ | Реестр, источники/парсеры, политика, роль/цитаты, несовпадение формы, отказ модели |
| test_evidence* / test_explanation* / test_staff_report / test_human_report | Применимость и ограничения, источники, точные цитаты, рекомендации и безопасный HTML |
| test_contracts / test_pipeline / test_money_extremes / test_cli / test_local_check | Однодиагнозный путь, суммы, файлы/команды/схемы и конфигурация |

Фикстуры синтетические; некоторые прежние source ID содержат исторические
обозначения. Это содержимое эталонов, а не специальный рабочий режим.
Статические тестовые провайдеры и клиенты не подключаются как сетевой резерв.
Прохождение структуры/цитат не является экспертным эталоном медицинской точности.

Новый дефект поведения сначала воспроизводится тестом. Ожидания независимых
сценариев задаются до запуска модели. Живой прогон запускается через `check_local.py`; вызовы модели
не включаются в автоматический pytest/CI. Реальные заявки не добавляются.
См. [независимые входы](../excel_cases/README.md), [примеры](../examples/README.md)
и [основной README](../README.md).
