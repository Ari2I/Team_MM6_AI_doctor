# Независимые Excel-входы

| Набор | Формат и назначение |
| --- | --- |
| [review_20261112](review_20261112/README.md) | Десять сохранённых двухлистных однодиагнозных входов; исторические SHA неизменны |
| [multidiagnosis_20261117](multidiagnosis_20261117/README.md) | Десять независимых входов нового формата, включая 1/2/10/50 диагнозов и ошибки ссылок |

Манифесты фиксируют ожидаемые свойства до реализации/прогона; файлы не
переписываются ради ответа модели. SHA и строки проверяются pytest.
Новые сценарии добавляются отдельными файлами со своими ожиданиями и происхождением.
Все данные синтетические; медицинский эталон предоставляет внешний специалист.
Исторические source ID/метаданные старых карточек не являются текущим режимом.

Рабочие пользовательские входы хранятся отдельно в [excel_input](../excel_input/README.md),
результаты — в .local. См. [тесты](../tests/README.md) и [README](../README.md).
