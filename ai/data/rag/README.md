# Версионированные данные RAG

В Git хранится манифест и процедура подготовки. Текущий manifest пуст:
право распространять полные имеющиеся копии ГРЛС/КР не подтверждено.
Пустой набор не объявляется рабочим корпусом и не активируется командой prepare.
Подтверждение прав даёт внешний владелец; библиотека проверяет зафиксированный
статус, но не устанавливает юридическое основание.

Разрешённые документы поступают отдельным пакетом с `manifest.json` версии
rag-data.1. Для каждого ресурса нужны resource_id, kind (registry/clinical/
corpus/policy/index), version, относительный path, sha256, source_url,
необязательный copy_url, retrieved_at с часовым поясом, rights_status=APPROVED
и конкретный rights_basis. Доступность страницы в интернете не заменяет права.
В наборе запрещены заявки, персональные данные, результаты, .env и ключи.

```powershell
python -m llm_rag.rag_data prepare --manifest package/manifest.json --source-dir package --data-dir .local/rag-data
python -m llm_rag.rag_data check --data-dir .local/rag-data
```

Команды не обращаются к сети. Весь исходный набор проверяется до копирования,
затем повторно сверяется в staging и атомарно активируется через current.json.
Версии лежат в versions/<SHA манифеста>. Старый активный набор сохраняется
при ошибке подготовки. Повторное успешное выполнение идемпотентно.
Незавершённые .staging не читаются runtime; их не нужно копировать в поставку.

`RAG_DATA_DIR` задаёт общий корень; `--data-dir` имеет приоритет в команде.
В исходниках по умолчанию используется этот каталог data/rag; установленный
пакет использует каталог данных ОС (LOCALAPPDATA либо XDG_DATA_HOME).
Алгоритм не содержит личного абсолютного пути автора. Runtime может получить
проверенный ресурс через `load_data(root).resource_path(resource_id)`.

Полные исходники и производные индексы исключены из Git разрешающими правилами.
Модель/размерность/редакция эмбеддингов фиксируются в отдельном проверенном
кэше gigachat-vectors.1. МиниLM-векторы не принимаются новым провайдером.
См. [контракт результата](../../docs/integration-result.md) и [README](../../README.md).
